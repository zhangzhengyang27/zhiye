## 一、语雀真机取证（2026-09-21，桌面端 v4.x，AX 树 + 截图）

入口：文档编辑页右上角面板开关（评论与协作 / 操作与信息 / AI 写作）→「操作与信息」菜单 →「查看历史版本」。**历史面板在独立于文档主视图的右栏内呈现**。

面板结构（无障碍树逐节点取证）：

```text
[图标] 历史记录                ← 面板标题是「历史记录」
[button 恢复此记录]            ← 头部唯一操作按钮，按 tab 换文案：
                                 全部记录→恢复此记录 / 版本→恢复此版本 / 本地缓存→恢复此本地缓存；
                                 无选中行时 disabled
[tabgroup]（radio 语义）
  radio 全部记录 = selected
  radio 版本
  radio 本地缓存
[checkbox] 仅显示已发布的历史记录 = 0
[checkbox] 显示所有本地存储版本 = 1   ← 默认勾选，与上一过滤并存于「全部记录」页
[list] 行（pressable，无勾选框、无批量、无行内操作按钮）
  行 = 时间 + 状态标签 + 作者
  状态标签实测值：已发布 / 离线保存
  例：今天 16:15 · 已发布 · 程序员小叶；今天 16:15 · 离线保存
「版本」tab 空态：暂无版本记录
选中行 → 面板内出现该版本预览
```

locale 佐证（root_en-US.js）：`保存为版本`(1123)、`修改版本名称`(1160)、`删除该版本`(1574)、`复制版本链接`(2193)、`恢复此版本/恢复到此版本/恢复这个版本`(3066-3075)、`是否要删除该历史版本`(3878)、`回退到历史版本会导致当前正在编辑的未保存内存丢失，请确认操作`(2012)、`暂无历史版本`(3927)、`显示所有本地存储版本`(3887)、`仅显示已发布版本`(812)、`已存为版本：`(2596)、`对比#doc_version_diff`(2398)。
