# 文档大纲：切换到 Lake 原生 TOC — 2026-09-21

> **文档状态**：✅ 已实施 + 断言验证通过
> **起因**：用户指出编辑器（yuque-editor-core / Lake）**自带大纲**，不该自行封装。首个实现（自建 DocumentOutlinePanel + outlineItems 缩进列表）按用户意见废弃，改用内核原生 TOC。

## 语雀与内核证据

- **语雀真机**（AX 取证）：文档页大纲在编辑器侧栏（「大纲」+ 层级缩进条目，点击跳正文）。
- **Lake 内核**（packages/core 源码 + doc.umd.js）：
  - 封装层 `editor.ts` 已有 `showToc` 选项 → `toc: { enable }`；
  - toc 插件启用后注册 **`toggleTocView`** 命令，侧栏对象含 `toggleTocSidebar/close/getPinStatus`；
  - 侧栏容器 = `.ne-ui-sidebar { right: 0 }`（**右侧 305px**，与语雀产品一致）；展开态 `.ne-editor` 挂 `.ne-normal-toc` 类，正文 `margin-right: 280px` 避让（core 的 `ensureTocAvoidanceStyle` 已注入不依赖 `.ne-doc-major-editor` 祖先的等价规则）；
  - vue 层 `YuqueRichText` 已透传 `showToc` prop 并 expose `execCommand`。
- **DOM 实证**：Lake 渲染标题为自定义元素 `ne-h1..ne-h4`（非 h1-h6 标签）——旧跳转选择器 `h1..h4` 因此静默失效（`jumpToOutlineItem` 找不到任何节点），已修。

## 实现（前端，两个文件 + 一个删除）

- `components/editor/YuqueDocEditor.vue`：新增 `showToc` prop（透传 YuqueRichText，启用 toc 插件）；`defineExpose({ toggleToc })` → 内部 `execCommand("toggleTocView")` 运行时开关侧栏（不重建编辑器）。
- `views/knowledge/KnowledgeDocEditorView.vue`：编辑器实例挂 `show-toc` 与 `ref="lakeEditorRef"`；顶栏「目录」按钮 → `lakeEditorRef.toggleToc()`（阅读态也可用）；原「操作与信息」按钮独立（i-lucide-info）；`jumpToOutlineItem` 选择器改为 `ne-h1..ne-h4`（信息面板大纲小节的跳转一并修复）。
- 删除 `components/editor/DocumentOutlinePanel.vue`（自制左栏，按用户意见废弃）。
- 信息面板内的大纲小节保留（outlineItems + 修复后的跳转）。
