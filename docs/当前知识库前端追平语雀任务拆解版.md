## 2. P0：统一块模型基础

### FEAT-P0-01 抽象统一块容器骨架

**目标**

为高频内容块建立统一的块级交互容器，形成后续块能力收敛基础。

**涉及模块**

- `src/components/editor/RichTextEditor.vue`
- `src/components/editor/extensions/*`
- 富文本节点装饰与块状态相关逻辑

**核心改动点**

- 抽象统一块容器的视觉与交互骨架
- 统一承接 hover、selected、insert-after 等状态
- 统一块左侧操作区与更多菜单承载方式
- 收敛现有块状态 class 与绑定逻辑，避免继续散落在各节点实现里

**验收标准**

- 高频内容块可通过同一套块状态机制接入
- hover、选中、插入反馈不再各自实现一套样式和逻辑
- 不影响当前 Markdown / HTML 内容保存与回显

**依赖关系**

- 无，P0 起始 issue
