
### 2.1 整体骨架：三栏

窗口 1247pt 宽实测分栏（截图 2/3 缩放换算）：

```
┌ 全局侧栏 ≈250pt ┬ 知识库目录列 ≈250pt ┬ 主内容区 ≈750pt（自适应）┐
```

- 两列侧栏宽度接近相等（各 ≈250），主内容占剩余全部
- 目录列有独立的列头与「首页/目录」双 tab，与全局侧栏之间无拖拽条（本次实测未见拖拽把手，xiaoye 现有的可拖拽能力可保留为增强项）

### 2.2 全局侧栏（自上而下）

1. 头部一行：左「语雀 ⌄」logo+下拉；右用户头像
2. 搜索框（灰底圆角，placeholder「搜索」，右侧 `⌘ J`）+ 独立「+」新建按钮
3. 导航（图标+文字，选中浅灰高亮）：开始 / AI 写作 / 小记 / 收藏
4. 「知识库」分组头（⌄ 可折叠，右侧展开箭头 >）
5. 知识库平铺列表：书本图标 + 名称，个人库带共享角标；选中项浅灰底
6. 底部 border-t 分隔 +「更多」按钮

### 2.3 知识库目录列

- 列头：`<` 返回 + 书本图标 + KB 名 + 邀请图标 + 绿色「+」新建按钮（右上角）
- tab 行：**首页（房子图标）/ 目录（列表图标）双 tab**，右侧齿轮（设置）+ 大纲图标
- 树：折叠箭头 + 类型图标 + 标题，缩进紧凑；选中行浅灰圆角底
- 行 hover：浮现 `⋯`（更多菜单）、`👁`（阅读模式，仅文档）、`+`（目录=添加子内容 / 文档=新建同级文档）内联图标（2026-09-06 复核用户提供的原版截图修正：此前误记为 @）
- 右键菜单（9 项，白底圆角 8、行高紧凑、图标+文字）：重命名 / 复制链接 / 在新窗口打开 / 移出目录 / 复制… / 移动… / 导出… / 置顶文档 / 删除

### 2.4 知识库首页（目录列「首页」tab 或进入 KB 默认页）

- 头部：大文档图标 + KB 名（≈27pt 粗体）；右上「☆ 收藏」「分享」「⋯」
- 统计行：`17 文档  7688 字 ⓘ` + 创建者头像
- 内容 = 目录式列表（**带点线 leader**，时间右对齐）：
  - 文档行：`标题 ······· 05-25 19:01`
  - 文件夹行：`> 标题 ·······`（带展开箭头，无时间）
  - 与目录树同序混排
