## 一、色彩 token：与本项目一致，无需改动

网页端 default（亮）主题的色板与 `tokens.css` **逐值一致**：

| 语义 | 语雀网页 light | 本项目 `tokens.css` |
|---|---|---|
| 品牌 `--yq-theme` | `#00b96b` | `--kb-brand = green-600 #00b96b` |
| 主文字 `grey-900` | `#262626` | `#262626` |
| 底色 `background-base` | `#fff` | `#fff` |
| 一级灰 `grey-100/200/300/400/500` | `#fafafa/#f4f5f5/#eff0f0/#e7e9e8/#d8dad9` | 相同 |
| 文字层次 | text-primary=grey900 / body=grey800 / caption=grey700 / disable=grey600 | ink / secondary / tertiary / quaternary = 相同映射 |
| 链接 `text-link` | `blue-600 #117cee` | 同 |

暗色 pouli：theme `#2ed790`、grey-100 `#141414`… grey-900 `#e2e2e2`，与 `.dark` 块一致。
主题切换挂在 `<html data-kumuhana="default | pouli">`。

**结论：颜色不是差异来源，差异在布局结构与组件密度。**

## 二、工作台 / Dashboard 布局实测

```
┌ 侧栏 ~278px
│ ├ Logo「语雀」+ 用户头像（右上）
│ ├ 搜索框（高32，宽185，⌘ J 提示）
│ ├ 一级导航 行高32：开始 / AI 写作 / 小记 / 收藏
│ └ 二级区「知识库」(可折叠)：展开 = 知识库列表（36 个平铺，非目录树）
└ 主内容（从 x≈290 起，浅灰/白底）
   ├ 快捷卡 4 个并排（首次见 y143）：新建文档 / 新建知识库 / 模板中心 / AI 帮你写
   │    尺寸实测 ≈259 × 55，圆角 8，图标在左，双行文字（主 14/500 + 副 12）
   ├ tab「文档」标题行
   ├ segmented 控制条（高24，14/500）：编辑过 / 浏览过 / 我点赞的 / 我评论过
   ├ 列筛选表头：类型 | 归属 | 创建者（下拉，13-14px，#585a5a）
   └ 文档行（标题行高 32，字号14，hover 浅底，行距 ~65 含 padding）：
         标题 → 操作者 / 知识库 / 时间（今天 HH:mm / MM-DD HH:mm / YYYY-MM-DD）
```

## 三、知识库主页实测

- 头部：知识库名 + 收藏 + 分享 + 统计（`N 文档 · N 字`）+ 创建者头像
- 主区即**目录**：文件夹可折叠，文档行 = `标题 + 更新时间`
- 左侧导航 = 当前知识库文档树（目录 tab + 首页 tab + 搜索 ⌘J）——**编辑器与主页共用同一左侧栏（单层）**

## 四、文档编辑/阅读页实测

- 左侧单侧栏 = 当前知识库目录树（可拖拽排序，行内按钮操作）
- 顶部工具条：返回 + 面包屑「文档与技巧 / 测试」+ 类型「MD」+ 工具图标 + 分享 + 编辑
- 正文后元信息：作者 / 时间 / 点赞 / 评论
- 无第二层侧栏、无右侧大纲常驻

## 五、与本项目当前实现的差距（按影响排序）

| # | 维度 | 真实语雀 | 项目现状 |
|---|---|---|---|
| 1 | 侧栏结构 | 单层：进 KB 后左侧即目录树 | 双层：全局侧栏(248) + 工作区目录树(296) |
| 2 | 快捷卡 | 新建文档 / 新建知识库 / 模板中心 / AI 帮你写；高约55 | 新建文档 / 新建目录 / 新建画板 / 从模板创建；更高(~76) |
| 3 | 文档 Tab | segmented：编辑过/浏览过/点赞/评论 | 下划线 tab：最近访问/最近更新/全部 |
| 4 | 行信息 | 标题→操作者/知识库/时间（右排三列） | 徽章 + 标题 + meta + time（近似，列少） |
| 5 | 侧栏宽度 | ~278 | 248 + 可拖 |
| 6 | 字号 | 正文 14 / 标题等 | 已按 14 收紧 |
