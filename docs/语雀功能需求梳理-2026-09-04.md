### 2.5 文档编辑器（核心）

**顶栏（文档头）**：

- 标题 + 「已加载最新版本」状态 + 云端图标；右侧依次：星标、**复制为 Markdown 格式**、**协作者**、**讨论**、**分享**、三个面板开关（评论与协作 / 操作与信息与样式设置 / AI 写作悬浮窗）

### 2.9 偏好设置（桌面端本地 `/setting` 路由）——2026-09-19 复刻完成

**规格来源**：`yuque-source/build/renderer/76858.js`（设置页组件 `ze`/`Re`，未压缩可读，中文 label 即代码原文）+ `app/main/isomorphic/constants/{color-theme,shortcut,proxy,storage}.js` + `build/renderer/76858.theme.css`。入口只有两处（`app/main/menus/application.js`、`menus/tray.js`）：Application 菜单与托盘的「偏好设置 ⌘,」，均要求已登录；**渲染层没有齿轮**。点击后主窗口路由到本地 `/setting`（与 `/load-failure`、`/recovery` 同级，整页替换、无返回按钮，靠 History 前进后退离开）。

**布局**：单列、整页滚动、**无左侧导航**。h1 726px 居中 + margin-top 30（语雀未给 h1 字号，走 UA 2em，body 14px 即 28px）；内容列 780px、内缩 32；h2 16px/上下 24；行 32 行高 + margin-top 24 + padding-bottom 32 + 1px 下分隔线（末组无）；antd `Row + Col span=18/6` 等价 75%/25% 分栏。

**9 个分组（render 顺序）**：颜色主题（当前主题：暗黑/浅色/跟随系统）→ 语言和时间（**只有显示语言**，无时间项）→ 启动和登录（开机自启）→ 全局快捷键（6 行可编辑 + 右上「更多快捷键」外链）→ 桌面端锁定（isYuque 才出现）→ 代理设置（启用/模式 HTTP·PAC/协议 HTTP·SOCKS4·SOCKS5/服务器 + 「设置代理地址」弹窗）→ 其他设置（**仅 macOS**，状态栏图标开关）→ 加入内测版体验计划 → 关于+产品名（版本行 + 更新日志/常见问题/问题反馈/服务协议四条链接）。

**不在设置页、只在菜单里**（易误加）：关闭硬件加速、清理应用缓存、检查更新、视图缩放（zoom 0.75–2.00）。

**快捷键族**：`globalShortcut`（主窗口/小记/锁定/AI 框）由主进程注册，`mousetrap`（新建文档 ⌘N、全局搜索 ⌘J）由渲染层按键监听消费；落盘 key 是 `custom-short-cut`（常量表里的 `custom-keyboard-shortcut` 是死值）；macOS 显示 `⌘ ⌥ ⇧ ^` 空格分隔、Windows `Ctrl + Alt + Shift` 用 `" + "` 分隔；取消写哨兵 `NO_SHORTCUT`；冲突提示「该快捷键已被占用，请重新设置」。输入件里 **readonly 输入框恒空**，文字只由绝对定位的 tip 浮层渲染（浮层底色半透明，输入框再放一份会重影）。

**本仓实现与偏差**（`views/settings/DesktopSettingsView.vue` + `components/settings/`，路由 `/settings`）：
- 9 组全保留；「语言和时间」（无 i18n）、「桌面端锁定」（无锁屏窗口与密码流程）、「加入内测版体验计划」（无更新通道）三组按原样呈现但禁用并加一行缺失说明；关于组的四条外链取址未定，空即置灰（不拿语雀地址凑数）。
- 入口三处：macOS Application 菜单 + 托盘「偏好设置 ⌘,」（语雀同源）+ 侧栏底部「更多」内联区一条（Web 端无原生菜单，必须给可见入口）；Web 端另在渲染层兜底绑 ⌘,。
- 存储：值一律 localStorage（一项一 key，对齐语雀「一个 key 一个 json 文件」），桌面必需项写入时下发主进程生效，主进程另存 `userData/desktop-settings.json` 快照只为下次启动提前应用。颜色主题例外——沿用 `vueuse-color-scheme`（index.html 防闪烁脚本读的就是它），不另存第二份。
- 文案里的产品名由「语雀」换成「知识库」（自启、主窗口、状态栏三处）。
- **代理是否生效只能用非 loopback 目标验证**：Chromium 默认对 localhost/127.0.0.1 直连 bypass，把代理指向 `127.0.0.1:9` 再去请求 `localhost:3200` 看不出任何差异（第一版验证脚本就是这么假通过）。桌面端验收改用本机局域网 IPv4 打后端（后端监听 `*:3200`），断言「基线通 → 死代理必失败 → 关掉恢复」。
- 桌面端真跑：`pnpm dev --remoteDebuggingPort=9222` 起实例后 `pnpm verify:settings:native`（开机自启翻转并还原、globalShortcut 注册/占用拒收/NO_SHORTCUT 真注销、代理落 session、托盘销毁重建、快照落盘）。系统级热键的「按下触发」仍无法自动化——合成按键能触发菜单 accelerator（⌘, 实测可）但触发不了 globalShortcut。
- Web 端禁用开机自启/代理/状态栏图标/全局族快捷键并标注「仅桌面端可用」。
- 主题由二值 toggle 升级为三态；`useDark` 的 getter 是 `mode === "dark"`，「跟随系统 + 系统为暗」时会与 `<html>.dark` 脱节（编辑器 dark-mode 依赖它），故改用 `useColorMode({ emitAuto: true })` + `.state` 解析。

**主窗口尺寸（实测语雀 `app/main/windows/size-manager.js`）**：语雀从不写死窗口大小。无历史尺寸时按
主屏工作区分档（<=1024 给 1000x640；<=1280 给 0.9w x 640；<=1440 给 0.9w x 720；<=1680 给
min(0.9w,1440) x 800；更大给 0.8w x 0.8h），最小 720x640；有历史尺寸且装得进当前屏幕就用历史值
（`main_position` + sizeManager）。所以「语雀的设置窗口看着小」是用户自己拖小后被记住了，
不是设置页另有小窗形态。本仓已实现同一分档 + 几何持久化（`userData/desktop-settings.json` 的
`windowBounds`，resize/move 去抖 400ms 落盘，只记主窗），但全局最小宽仍停在 1080
（工作区壳写死 min-w-[1080px]，语雀是 720）。

**入口形态偏差（2026-09-19 产品决定）**：语雀点「设置…」是在主窗口内**整页替换** `/setting`
（实测：点击后窗口列表不变），本仓按用户要求改为**独立窗口**——830x768、最小 720x640、单例
（重复打开只把它唤到前台），菜单/托盘/侧栏三个入口共用主进程 `openSettingsWindow`。
连带好处：设置页想要窄不再需要临时放宽主窗口最小宽（那套 `router.afterEach` 补丁已删——
先前的组件卸载钩子版本在整页刷新时根本不触发，主进程最小宽会永久停在放宽值，实测踩过）。
设置页内容列由定宽 780 改为上限宽 780，窄窗下收缩而不横向溢出。

### 5.1 数据表 = 独立的「多维表格」文档类型（重要发现）

- 右侧：「使用此模板」按钮 + 三个来源 tab：**推荐（官方）/ 本知识库 / 我的** + 分类树（团队协作：会议记录、工作汇报、项目立项、用研报告、需求文档、需求管理、系分文档、缺陷管理、故障复盘、接口文档、项目复盘；个人管理：折叠）

对比当前项目：TemplateSelectDialog 只覆盖「我的/本知识库」形态，缺官方推荐库与分类浏览、缺预览面板。

### 5.4 编辑器块级交互（实测补全）

- 光标进入段落/悬停时，块左侧出现 **⋮⋮ 拖拽手柄**（tooltip「开始拖动以移动」）
- 点击手柄：**选中整块（蓝色高亮）+ 弹出块菜单**：转为 >、删除、复制、剪切、缩进 >、在下方添加 >
- **「转为」子菜单为图标矩阵**：H1–H6、正文、有序/无序列表、待办、高亮块、引用、**分栏、折叠块**

### 5.5 阅读模式（整页形态）

- 顶栏被替换为一个绿色「**编辑**」按钮（切回编辑态）
- 正文只读；文末依次为：**点赞区**（👍「若有收获，就点个赞吧」）、文档元信息行（作者 / 更新时间 / 评论数 / 点赞数 / **IP 属地**）、「分享到」社交图标
- 最底部**文内评论框**（头像 + 输入区 + 轻量格式栏 + 发布）；右下角浮动 👍 与 💬 按钮

### 5.6 知识网络（双链图谱）

「操作与信息」面板顶部的入口，打开为大幅弹窗：

- 左侧：**关系图谱画布**（文档为节点）
- 右侧：文档卡片（标题/作者/更新时间）+ **被引用 (N) / 引用了 (N)** 两个 tab（反向链接/正向链接），空态文案「本文档暂未被其他文档引用」
- 底部提示：双击打开、帮助文档

### 5.7 其他补充确认

- **文档图标**：文档标题上方 hover 出现「添加图标」，可给文档设置图标
- **分享（私密态）**：分享弹层显示「当前文档为私密，仅自己和协作者可访问」+ 添加协作者 + 「互联网公开(会员)」入口；说明文案指出公开分享需**实名认证 + 会员**。密码访问/站内公开搜索子设置仅公开文档可用，免费账号无法展开（需求仍按一轮记录保留）
- **知识库统计（会员）**：付费墙文案「购买会员可查看知识库的详细统计，如**文档数、点赞数、知识库各文档的阅读点赞数**等」
